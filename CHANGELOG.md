## [1.0.0] - 2026-09-09

### Added

- Initial release of the `frontcraft` skill
- 35-section operating guide covering the full web UI/UX development lifecycle
- Visual hierarchy and anti-generic design principles
- Accessibility, responsive design, and performance guidelines
- Evidence and truthfulness standards for data-driven interfaces
- 10-phase development workflow (Understand → Finalize)
- Functional UI rules: no dead controls, JS-file requirements, interaction audits
- Product-type-specific rules for marketing pages, SaaS apps, data-heavy UIs, research tools, and AI products
- Design review self-checks: human-eye test, anti-generic test, product-truth test
- `skills.json` manifest for one-command AGY installation
