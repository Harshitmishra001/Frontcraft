# Frontcraft

> A practical Antigravity skill for building high-quality web interfaces — from product understanding and UX decisions through implementation, accessibility, responsive behavior, and visual verification.

---

## Install

```bash
agy skill install https://github.com/Harshitmishra001/Frontcraft
```

That's it. The `frontcraft` skill will be available in any Antigravity session on your machine.

---

## What it does

Frontcraft turns your AI agent into a disciplined frontend engineer and UX practitioner.

It does **not** produce generic AI dashboards. It is an operating guide that forces the agent to:

- Understand the actual product before touching any UI
- Design from user goals, not component inventories
- Establish visual hierarchy before choosing colors
- Connect every interactive control to real behavior
- Use real application data — never fabricated placeholders
- Audit completed work for dead controls, placeholder content, and accessibility gaps
- Inspect the **rendered application**, not just source code

---

## When to activate

Activate `frontcraft` when you are:

- Building a new web UI from scratch
- Redesigning or substantially modifying an existing product
- Implementing a design from a reference screenshot
- Fixing UI quality issues (hierarchy, accessibility, responsiveness)
- Doing a visual or functional audit of a completed interface

Works with any web stack: plain HTML/CSS/JS, React, Vue, Svelte, Next.js, and others.

## Core philosophy

> Design the hierarchy before decorating the page.

> Real functionality is better than convincing simulation.

> A distinctive product identity is better than a generic AI aesthetic.

> Do not optimize the screenshot; optimize the human experience.
